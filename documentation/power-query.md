# Power Query Documentation

Power Query / M is used as the data preparation layer of the project.

## Main Responsibilities

- Data ingestion
- Data cleaning
- Data type standardization
- Data transformation
- Data preparation for the analytical model

## General Data Flow

```text
Source Data
    ↓
Power Query
    ↓
Data Cleaning
    ↓
Data Transformation
    ↓
Analytical Model
    ↓
DAX
    ↓
Power BI Report
