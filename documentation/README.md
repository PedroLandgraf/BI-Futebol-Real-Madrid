# Technical Documentation

## Project Architecture

The solution was developed in Microsoft Power BI using a structured analytical model designed to support football business intelligence.

The project combines:

- Data modeling
- DAX measures
- Power Query transformations
- Interactive visualizations
- Dynamic HTML-based components
- Custom SVG visualizations
- KPI analysis
- Drill-down and cross-filtering
- Data-driven visual storytelling

## Main Analytical Areas

### Matchday Analytics

Analysis of match attendance, ticket sales, revenue and stadium sector performance.

### Membership Analytics

Analysis of membership plans, revenue, cancellations and membership performance.

### Squad Intelligence

Analysis of the active squad, including:

- Player profile
- Position
- Age
- Height
- Dominant foot
- Nationality
- Market value
- Player attributes

## Interactive Features

The report includes dynamic interactions between visuals and analytical components.

Examples include:

- Dynamic team logos based on selected matches
- Dynamic player profiles
- Dynamic nationality visualization
- Dynamic position analysis
- Dynamic player attribute visualization
- Stadium heatmap visualization
- Interactive tooltips
